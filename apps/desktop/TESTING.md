# 基于文件的网页测试

桌面端进入「测试」模式，通过「导入测试文件」、附件按钮或拖放批量导入需求资料和 `.xlsx` 用例。输入任务，例如：

> 根据这些需求和 Excel 用例中的地址测试网站，把执行状态、实际结果和报告链接更新到 Excel，给我下载结果。

也可以从侧栏「浏览器测试」导入材料，点击某个文件的「根据此文件测试」。导入资料支持 XLSX、DOCX、PDF、PPTX、TXT、Markdown、CSV 和 JSON；每批最多 32 个文件，单个最多 16 MiB，总计最多 64 MiB。旧版 `.xls` 需先另存为 `.xlsx`。

助手读取工作表与单元格位置，根据实际步骤操作独立浏览器。网页状态和登录在同一对话中保留，关闭会话或空闲十分钟后结束。网站需要的登录资料未提供时，助手会询问或将相关用例标记为未执行。

结果由真实浏览器报告生成：断言通过、失败、已操作但未断言、未完成，或有原因的未执行。结果写入已有结果列或新增的「执行状态」「实际结果」「测试报告」列。源文件保持不变，生成带版本号的更新版 Excel；可从对话下载链接或「浏览器测试 → 更新后的 Excel 用例」下载。

更新会保留原工作簿的其他 ZIP 部件及未修改单元格，包括样式、公式、合并区域和图片。结果列不能覆盖需求列、公式单元格或合并区域的从属单元格。多工作表或较大用例表可分批更新，每批最多 200 行，继续更新会使用最新版本。
